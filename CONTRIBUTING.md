# Contributing to AviOrg Studio

Thanks for helping improve AviOrg Studio. Please open an issue before large changes. Keep the offline browser architecture and developer credits intact.

1. Work on a feature branch, not directly on `main`.
2. Edit the appropriate files under `assets/css/` or `assets/js/`.
3. Verify `python scripts/check_repo.py`, rebuild the offline edition with `python scripts/build_standalone.py`, and run the smoke tests.
4. Test charts, Excel upload, PowerPoint export, local project recovery, and keyboard navigation.
5. Open a pull request describing the change, with screenshots if it affects layout.

**Never commit real employee data, local access credentials, API keys or non-anonymized project backups.**
