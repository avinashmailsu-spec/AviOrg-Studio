# GitHub upload checklist

- [ ] Create a repository named `aviorg-studio` in your GitHub account.
- [ ] Choose Public (public site/code) or Private (plan-dependent Pages availability).
- [ ] Extract `AviOrg_Studio_GitHub_Repository.zip` and upload the **contents** of its `aviorg-studio` folder, preserving `.github` and `.nojekyll`.
- [ ] Confirm the default branch is `main`.
- [ ] Go to Settings → Pages → Source → GitHub Actions.
- [ ] Confirm both CI and Pages workflows succeed in Actions.
- [ ] Open the Pages URL listed in the successful deployment.
- [ ] Select a copyright/license policy before inviting outside code reuse (docs/LICENSING.md).
- [ ] Never commit confidential employee spreadsheets, project backups, or API keys.
