# AviOrg Studio Pro 6.3 — Signature Luxe

## New appearance

- Redesigned the application shell with a jewel-tone enterprise color system and a deep gradient navigation rail.
- Introduced polished glass-style side panels, elevated chart canvas, richer active states and clearer hierarchy.
- Added **Royal**, **Ocean** and **Emerald** workspace finishes in the **Design** panel; these are locally saved and do not modify an organization's data or card design.
- Updated the initial example chart to a colorful, department-based *Frosted* style for new users. Existing saved projects retain their own card settings.
- Improved theme responsiveness, reduced-motion support, keyboard focus states and control contrast.

## Preserved

Visual chart editing, 500 chart-style combinations, Excel/CSV imports, editable PowerPoint exports, scenario planning, workforce intelligence, matrix reporting, project backup and prior import/export tools remain available.

## Deployment

The standalone application runs offline. This package also contains a GitHub Pages-ready modular website and GitHub Actions workflow. Live Microsoft 365 synchronization, cloud collaboration, hosted AI and secure publishing require additional services.
