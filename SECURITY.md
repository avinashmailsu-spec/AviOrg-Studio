# Security policy

This project is an offline-first browser editor and a public static site. It is **not** an authenticated cloud HR system. Avoid committing real employee records, API credentials, or non-public workforce information.

If you identify a vulnerability, contact the repository owner privately through GitHub's security reporting interface if enabled. Otherwise, contact the maintainer using a private channel rather than publicly disclosing a working exploit or personal data.

Client-side input validation and local review controls are not server-enforced access controls. Microsoft 365 connections and enterprise collaboration require a secure, separately deployed service.
