# Signature Luxe appearance

AviOrg Studio Pro 6.3 has three visual finishes for the app's workspace:

- **Royal** — indigo, sapphire blue and violet accents.
- **Ocean** — blue, cyan and teal accents.
- **Emerald** — jade, marine and green accents.

Open **Design → Studio appearance** to switch between them. The choice is saved locally in the browser and does **not** change organization data, reporting structure or card theme. Existing charts and their 500 design combinations remain separate.

The refreshed example chart starts in a **color-by-department Frosted style** on a fresh browser profile. If you have previously saved project state, the app preserves that data and its chart styles.

The screenshot gallery in the main README displays real captures of the application UI. Editing, imports, exports, scenario planning and workforce tools remain available.

**Deployment:** the standalone HTML is offline-capable; the modular website can be served on GitHub Pages. Authenticated Microsoft 365 live sync, enterprise collaboration and hosted AI are not part of this static release.
